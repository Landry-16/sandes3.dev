summary: The in-house tool of my freelance business, from finding shops with no website to delivering their site.
---

P-Finder finds local shops that have no website, sorts them, prepares calling sessions with scripts, generates PDF quotes and tracks every client project (domain name, hosting, delivery).

## Key points

- Shared Supabase database, with an account for each team member.
- Search through OpenStreetMap or Google Places, with manual keyboard sorting.
- Each client site is created in its own GitHub repository, from templates per type of shop, and stays independent: the client can host it elsewhere.
