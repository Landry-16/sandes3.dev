A desktop app for Windows, macOS and Linux that brings together everything an author needs: capture ideas, structure the work, write, track progress and export the manuscript.

## Key points

- A **Tauri 2** app: React interface, Rust core, data stored locally in SQLite.
- Optional accounts with Supabase; the app stays fully usable offline.
- Character sheets with relationships, a world map editor and a focus mode for distraction-free writing.
- Working MVP; next step: user testing.

The repository is private, only previews are shown here.
